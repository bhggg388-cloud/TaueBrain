# けんちょう即答ドリル

47都道府県と県庁所在地を、両方向（都道府県→県庁所在地／県庁所在地→都道府県）から即答できるようにする小学生向けの練習アプリ。`index.html` 1ファイルで動きます。

## しくみ
- 4択・ふりがな付き。選択肢に1〜4の番号があり、キーボードの数字キーでも回答できる（Enterで次へ）
- 都道府県→県庁所在地の選択肢は、同じ都道府県にあるほかの市（例：宮城県→仙台市／石巻市／気仙沼市／大崎市）。県庁所在地→都道府県は同じ地方の都道府県
- 設定した秒数（初期値2秒）以内の正解を「即答」として記録
- 問題ごと（47×2＝94問）にレベル0〜4を管理
  - 即答で +1、ゆっくり正解はレベル2まで、まちがいは0に戻る
  - 即答を4回つづけると「即答マスター」
- 出題は、にがて・まだ出ていない問題ほど出やすくなる重みづけ。しばらく出ていないマスター問題も復習として出る
- まちがえた問題は3問あとにもう一度出題。終了後に「まちがえた問題をもう一度」
- 「にがて特訓」：まちがえた・時間がかかった問題だけを出題
- 「名前がちがう県」：北海道→札幌市、愛知県→名古屋市など18か所だけを練習
- 地方ごとの出題範囲、問題数（5/10/20）を選べる
- きろく画面：おぼえぐあい、にがてランキング、2週間のグラフ、都道府県ごとの状態、最近の回答

## やる気が出るしかけ
- ポイントとランク（ちずのたまご → … → でんせつの即答王）。即答10点、コンボでボーナス
- 即答コンボ表示（続くと効果音が上がっていく、5コンボごとに紙ふぶき）
- きょうのミッション3つ（クリアで+30ポイント）
- 60秒タイムアタック（最高記録を保存）
- にっぽん制覇マップ：両方向とも即答マスターした都道府県が金色になる日本地図

## 記録の保存
ブラウザの localStorage に保存します。claude.ai の Artifact として開いた場合は Artifact のデータベース（`progress/main`）にも保存され、別の端末でも続きから練習できます。設定画面からバックアップ用の文字列をコピー／読みこみできます。
